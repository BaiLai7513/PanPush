# 阿里云盘「应用内 WebView 登录」——可行性测试与实现

> 问题：阿里云盘能不能像迅雷/百度那样，用应用内 WebView 登录取到可用令牌？
> 设备基线：OnePlus PKR110 / Android 15 / APatch Root。日期：2026-10-12。

---

## 0. 结论

> **能实现，而且比迅雷更简单**（阿里没有请求签名，纯 Bearer）。
>
> - ✅ 阿里网页版 `www.alipan.com` 完整、可直接登录；
> - ✅ 网页端 client_id = `25dzX3vbYqktVxyX`，鉴权走 `auth.aliyundrive.com`；
> - ✅ 令牌刷新端点 `/token/refresh` 确认可用（JSON 入参）；
> - ⚠️ **App 的 refresh_token 与网页 client 不通用**（实测报 `InvalidParameter.ClientId`）——又一个"root 与 web 令牌不通用"的实例。

**做法**：WebView 登录 alipan.com → 读 `localStorage.token` → 取 `refresh_token` → `/token/refresh` 换 access_token → 调文件列表 API。

## 1. 实测证据

### 1.1 网页端 client 配置（从 `www.alipan.com` 页面实测）

```
client_id      = 25dzX3vbYqktVxyX
auth_endpoint  = https://auth.aliyundrive.com
redirect_uri   = https://www.aliyundrive.com/sign/callback
主 JS          = https://g.alicdn.com/aliyun-drive-fe/aliyun-drive-home/1.1.42/assets/index.js
```
（同款 client_id 也出现在阿里 App 内嵌 H5 里：`client_id:"25dzX3vbYqktVxyX"`）

### 1.2 令牌刷新端点行为（关键对照实验）

```
POST https://api.aliyundrive.com/token/refresh
Content-Type: application/json
x-requested-with: XMLHttpRequest
body: {"client_id": "<client_id>", "refresh_token": "<rt>"}
```

| 入参 | 返回 |
|---|---|
| `{"refresh_token":"test"}`（无效 token） | `InvalidParameter.RefreshToken` |
| 本机 App 的真 refresh_token + 无 client_id | `InvalidParameter.ClientId` |
| 本机 App 的真 refresh_token + `client_id=25dzX3vbYqktVxyX` | `InvalidParameter.ClientId` |
| 本机 App 的真 refresh_token + `client_id=76917ccccd354b13a68593d2ff5fe5a1` | `InvalidParameter.ClientId` |

> **解读**：无效 token 报的是 `RefreshToken`，真 token 报的是 `ClientId` → 说明
> **① 我们的 token 本身有效（通过了 token 校验）；② 但缺少"属于它的那个 client_id"**。
> 即 **refresh_token 与签发它的 client 绑定**，跨 client 刷新会被拒。
> → **App 的 refresh_token 不能直接给网页 client 用**（再次印证 §"差异与选型"的结论）。

### 1.3 阿里 App 的令牌存储（root 可读，供对比）

`com.alicloud.databox/databases/0.db` → `tb_user_info`：
```
user_id       = 06fa5787e7624bbe893237e0f3768ea2
drive_id      = 658161673
refresh_token = 0af4adfebad446ac925de65c4777b4f0      ← 32hex
```

## 2. 为什么"能实现"

- 阿里没有迅雷那种请求签名，**纯 `Authorization: Bearer`**；
- 网页版是完整的单页应用，**登录流程浏览器可跑**，令牌存 **localStorage** → WebView 的 `evaluateJavascript` 读得到；
- 网页登录拿到的 refresh_token 属于**网页 client**，用 `client_id=25dzX3vbYqktVxyX` 刷新即为"同 client"，可正常换 access_token。

## 3. 实现方案

### 3.1 流程

```
WebView 打开 https://www.alipan.com/（桌面 UA）
      │
      ▼
用户扫码/账号登录
      │
      ▼
evaluateJavascript 读 localStorage.getItem("token")
   → JSON：{ refresh_token, access_token, default_drive_id, user_id, expires_in, ... }
      │
      ▼
POST https://api.aliyundrive.com/token/refresh
   { client_id: "25dzX3vbYqktVxyX", refresh_token }
   → 新的 access_token / refresh_token / default_drive_id
      │
      ▼
POST https://api.aliyundrive.com/adrive/v3/file/list
   Header: Authorization: Bearer <access_token>
   Body: { drive_id, parent_file_id:"root", limit:100, order_by:"name", ... }
   ✅ 列出文件
```

### 3.2 抓取代码（关键）

```kotlin
/** 登录后从 localStorage 读阿里 token（通常是 JSON）。 */
private fun readAliyunToken(web: WebView, onToken: (String?) -> Unit) {
    web.evaluateJavascript(
        "(function(){try{return localStorage.getItem('token');}catch(e){return null;}})()"
    ) { v ->
        val raw = v?.takeIf { it != "null" }?.let { unquote(it) }
        onToken(raw)   // raw 形如 {"refresh_token":"...","access_token":"...",...}
    }
}

private fun unquote(s: String): String =
    if (s.startsWith("\"") && s.endsWith("\"")) s.substring(1, s.length - 1) else s
```

> 若 `token` 键读不到，**dump 整个 localStorage** 再按 `refresh_token` / `access_token` 找：
> ```kotlin
> web.evaluateJavascript("JSON.stringify(localStorage)") { ls -> /* 搜 refresh_token */ }
> ```

### 3.3 刷新 + 列文件（Kotlin）

```kotlin
object AliyunApi {
    private const val CLIENT_ID = "25dzX3vbYqktVxyX"

    /** 用 refresh_token 换 access_token。 */
    fun refresh(refreshToken: String, cb: (Boolean, String, String?) -> Unit) {
        Thread {
            try {
                val conn = (URL("https://api.aliyundrive.com/token/refresh")
                    .openConnection() as HttpURLConnection).apply {
                    requestMethod = "POST"
                    doOutput = true
                    setRequestProperty("Content-Type", "application/json")
                    setRequestProperty("x-requested-with", "XMLHttpRequest")
                }
                conn.outputStream.use {
                    it.write("{\"client_id\":\"$CLIENT_ID\",\"refresh_token\":\"$refreshToken\"}".toByteArray())
                }
                val code = conn.responseCode
                val body = (if (code in 200..299) conn.inputStream else conn.errorStream)
                    ?.bufferedReader()?.use { r -> r.readText() } ?: ""
                conn.disconnect()
                if (code in 200..299) cb(true, body, null) else cb(false, body, null)
            } catch (e: Exception) { cb(false, e.message ?: "err", null) }
        }.start()
    }

    /** 用 access_token 列根目录文件。 */
    fun listFiles(accessToken: String, driveId: String, cb: (Boolean, String) -> Unit) {
        Thread {
            try {
                val conn = (URL("https://api.aliyundrive.com/adrive/v3/file/list")
                    .openConnection() as HttpURLConnection).apply {
                    requestMethod = "POST"
                    doOutput = true
                    setRequestProperty("Authorization", "Bearer $accessToken")
                    setRequestProperty("Content-Type", "application/json")
                }
                conn.outputStream.use {
                    it.write(("{\"drive_id\":\"$driveId\",\"parent_file_id\":\"root\"," +
                              "\"limit\":100,\"order_by\":\"name\",\"order_direction\":\"ASC\"}").toByteArray())
                }
                val code = conn.responseCode
                val body = (if (code in 200..299) conn.inputStream else conn.errorStream)
                    ?.bufferedReader()?.use { r -> r.readText() } ?: ""
                conn.disconnect()
                cb(code in 200..299, "HTTP $code ${body.take(200)}")
            } catch (e: Exception) { cb(false, e.message ?: "err") }
        }.start()
    }
}
```

> 完整的 `AliyunLoginActivity` 见同目录 `AliyunLoginActivity.kt`。

## 4. 与 Root 直读对比（本轮实测）

| 项 | Root 直读 | WebView 登录 |
|---|---|---|
| 令牌 | App refresh_token（`0.db`） | Web refresh_token（`localStorage.token`） |
| client | App 客户端 | 网页客户端（`25dzX3vbYqktVxyX`） |
| 跨 client 刷新 | ❌ 实测 `InvalidParameter.ClientId` | ✅（同 client） |
| 需要 root | ✅ | ❌ |
| 需要签名 | 无 | 无 |

> **关键**：阿里 App 的 refresh_token **不能**用网页 client_id 刷新（实测），
> 反之网页 token 也应用网页 client_id —— **别混用**。
