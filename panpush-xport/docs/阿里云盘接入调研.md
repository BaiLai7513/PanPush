# 阿里云盘接入调研（真机实测）

> 设备：OnePlus PKR110（APatch Root）· 阿里云盘 App v6.18.0（`com.alicloud.databox`）已登录
> 结论一句话：**直链支持多线程且显著提速；但 ≥ ~100MB 的文件拿不到直链（第三方门控）。**

## 1. 匿名分享链路：不可行

| 步骤 | 端点 | 结果 |
|---|---|---|
| 分享令牌 | `POST /v2/share_link/get_share_token` | ✅ 匿名可用（JWT，user_id=anonymous）|
| 分享信息 | `POST /v2/share_link/get_share_by_anonymous` | ⚠️ 空 body |
| 列目录 | `POST /adrive/v3/file/list` + `x-share-token` | ✅ 可用 |
| **取直链** | `POST /v2/file/get_download_url` + `x-share-token` | ❌ `AccessTokenInvalid`（需登录态）|

前端 JS（`bundle.js`）对 `/file/get_download_url` 会注入 `x-signature`（白盒混淆），且分享下载仍需 access_token。

## 2. 登录态（root 直读 App 数据库）：可行 ✅

App 的 token 以**明文**存在 SQLite：`/data/data/com.alicloud.databox/databases/0.db`
表 `tb_user_info` 字段：`access_token / refresh_token / expire_time / drive_id / user_id`。

- 用 `Authorization: Bearer <access_token>` 调 `/v2/file/get_download_url` 即可拿到 OSS 直链。
- 示例直链形如：`https://cn-beijing-data.aliyundrive.net/...?x-oss-credential=...&x-oss-signature=...`（STS 临时凭证，15 分钟有效）。

## 3. 直链能力实测

| 项 | 结果 |
|---|---|
| 方法 | 仅 GET（HEAD → 403，签名只覆盖 GET）|
| Range | ✅ `206 Partial Content`，`Accept-Ranges: bytes` |
| 单连接限速 | ✅ 明显（~0.12 MB/s 起）|

### 多线程测速（66MB 文件，每档 5s，均 206）

| 连接数 | 速度 |
|---|---|
| 1 | 0.12 MB/s |
| 4 | 0.46 MB/s |
| 16 | 1.74 MB/s |
| 32 | 2.10 MB/s |
| 64 | 3.86 MB/s |
| 128 | 4.45 MB/s |

→ **按连接限速，连接数越多越快**；64 连接后收益递减（可能受本机网络/代理上行限制）。

## 4. 关键限制：文件大小门控 ⚠️

| 文件大小 | 取直链 |
|---|---|
| 1.7MB / 12MB / 33MB / 52MB / 66MB | ✅ OK |
| 127MB / 190MB / 1.6GB / 3.15GB | ❌ 返回 `url:""`（HTTP 200，软拒）|

- 阈值介于 66MB 与 127MB 之间，**疑似 100MB**（免费账号）。
- 与 `punish_flag` 无关（大文件该项也为 0）。
- 待确认：是否**会员**可解除；或属"第三方客户端"门控（官方 App 可下任意大小）。
- 另有**取直链频控**：短时间连续请求返回空 url，间隔 ~20s 后可恢复 → 集成需限速+重试。

## 5. 集成建议

- **可取直链的文件 → 多线程推 Gopeed，速度快**（价值高）。
- **>100MB 文件 → 直链拿不到**，需先确认会员能否解除；否则阿里只能作"小文件中转"用。
- Token 走 root 直读 DB，**可自动续期**（`refresh_token` 长期有效）→ 体验与迅雷一致，但更稳（token 明文本地读，无需拉起 App）。
