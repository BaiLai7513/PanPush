# 阿里云盘接入设计与实现

> 模块：`aliyun.py`（panpush 站点插件，零第三方依赖，自包含）
> 设备：OnePlus PKR110（APatch Root）· 阿里云盘 App `com.alicloud.databox` v6.18.0
> 结论一句话：**分享链 → 匿名列目录 → 转存到我的云盘 → 取 OSS 直链（可多线程）→ 回收副本**。小文件（≤100MB）可用，大文件受体积门控限制。

---

## 1. 背景与目标

网盘解析器要做的事只有两件：**拿到可下载的直链** + **把直链交给下载器多线程拉取**。
阿里云盘的特殊性在于：

1. 分享文件**不允许第三方直接下载**（返回 `Forbidden` / `ForbiddenNoPermission.File`）；
2. 取直链接口 `POST /v2/file/get_download_url` **必须登录态**（`Authorization: Bearer <access_token>`），匿名分享令牌 `x-share-token` 不被接受；
3. 直链是阿里 OSS（STS 临时凭证），支持 `Range`，但**按连接限速**；
4. 存在**体积门控**：大文件取不到直链。

因此设计目标：在**不依赖用户手动抓包**的前提下，自动完成「列目录 → 转存 → 取直链 → 回收」，并把结果适配成 panpush 的标准 `parse()` 输出。

## 2. 关键实测事实（2026-10 真机）

### 2.1 端点矩阵

| 用途 | 方法 & 路径 | 鉴权头 | 结果 |
|---|---|---|---|
| 分享令牌 | `POST /v2/share_link/get_share_token` | `X-Canary` | ✅ 匿名可用，返回 JWT（2h） |
| 分享信息 | `POST /v2/share_link/get_share_by_anonymous` | `x-share-token` | ⚠️ 空 body，但 list 够用 |
| 列目录 | `POST /adrive/v3/file/list` | `x-share-token` | ✅ 匿名可用 |
| **转存** | `POST /v2/file/copy` | `Authorization` + `x-share-token` | ✅ 返回新 `file_id` |
| **取直链** | `POST /v2/file/get_download_url` | `Authorization` | ✅ 需登录态 |
| **回收** | `POST /v2/recyclebin/trash` | `Authorization` | ✅ |
| **续期** | `POST /v2/account/token` | body `grant_type=refresh_token` | ✅ |

> 说明：`adrive`/`v3`/`v4`/`v5` 下的 copy 端点均 **404**，只有 `/v2/file/copy` 有效；取直链只有 `/v2/file/get_download_url` 认 `Authorization`，`get_share_download_url` 等变体不存在。

### 2.2 直链特性

- host 形如 `cn-beijing-data.aliyundrive.net`（阿里 OSS）。
- `HEAD` → **403**（签名仅覆盖 GET，别用 HEAD 探活）。
- `GET` + `Range: bytes=0-99` → **206 Partial Content**，响应头 `Accept-Ranges: bytes`。
- 与 UA 无关（浏览器 UA / AliApp UA 均可）。
- **按连接限速**：单连接被限速，多连接线性叠加。66MB 文件实测：

  | 连接数 | 1 | 4 | 16 | 32 | 64 | 128 |
  |---|---|---|---|---|---|---|
  | 速度 MB/s | 0.12 | 0.46 | 1.74 | 2.10 | 3.86 | 4.45 |

  → 结论：**阿里直链能多线程提速**，但 64 连接后趋于饱和（疑似本机 mihomo 上行到顶）。故默认并发取 **64**。

### 2.3 体积门控（决定集成边界）

| 文件大小 | 能否取直链 |
|---|---|
| 1.7 MB / 12 MB / 33 MB / 52 MB / 66 MB | ✅ |
| 127 MB / 190 MB / 1.6 GB / 3.15 GB | ❌（HTTP 200，`url` 字段为空 = 软拒） |

- 阈值介于 **66MB 与 127MB** 之间，高度疑似 **100MB**（免费账号门控）。
- 与 `punish_flag` 无关（大文件该项也为 0）。
- **保守处理**：`SIZE_GATE = 100 * 1024 * 1024`，≥该值的文件跳过并写入 `notes`。
- **待确认**：会员是否解除该门控尚未验证（用户未提供会员信息，按免费账号保守处理）。

### 2.4 取直链频控

连续请求取直链会返回空 `url`，间隔约 **20s** 后恢复。`AliyunParser.download_url` 内建 3 次退避重试（gap=15s）。

### 2.5 凭据存储

阿里云盘 App 的 token **明文**存于 SQLite：

```
/data/data/com.alicloud.databox/databases/0.db   →  表 tb_user_info
字段：user_id / access_token / refresh_token / expire_time / drive_id / ...
```

- 其它文件（`AUTH_APP_INFO.xml`、`injectCookieNew`、`AUTH_DEVICEINFO.xml`）均为**加密态**，无用。
- 复用 `xunlei.py` 同款 root 直读思路（拷贝 DB + WAL 后用 `sqlite3` 只读打开，按 `expire_time` 取最新）。
- **回收后直链仍可用**（STS 签名独立于文件是否在列），故默认「取到直链→回收副本」安全。

## 3. 模块设计

### 3.1 公开接口（对齐 panpush 约定）

```python
class AliyunParser:
    def __init__(self, url, passcode="", cookie=None, timeout=20, token=None): ...
    def parse(self, list_only=False) -> dict:
        # {"site": "aliyun", "files": [...], "downloads": [{url,name,headers}], "notes": [...]}

COOKIE_GUIDE = (...)      # 集成后由 panpush 注册为 COOKIE_GUIDE["aliyun"]
```

`parse()` 的 `notes` 用于承载「超门控跳过」「频控重试」等提示，`downloads[].headers` 携带必要请求头，直接喂给 Gopeed。

### 3.2 内部函数

| 函数 | 职责 |
|---|---|
| `is_aliyun_url` / `extract_share_id` / `extract_passcode` | URL 解析 |
| `read_app_creds` | root 直读 App SQLite（拷贝 DB+WAL → sqlite3 查询） |
| `read_saved_creds` / `load_creds` / `creds_from_text` | 从 `.cookie.aliyun` 或文本加载/解析凭据 |
| `creds_expire_soon` / `refresh_creds` | 过期检测 + 刷新（`/v2/account/token`） |
| `_get_share_token` | 取分享令牌（JWT） |
| `list_files` / `_walk` | 匿名递归列目录 |
| `copy_file` | 转存到我的云盘 |
| `download_url` | 取直链（空 `url` 退避重试） |
| `trash` | 回收副本 |

### 3.3 流程

```
URL
 ├─ 有 App 凭据？ ── 否 ─→ .cookie.aliyun / 文本凭据
 │                        └─ 都无 ─→ 报错并提示登录 App
 ├─ 凭据将过期？ ─→ refresh_creds()
 └─ parse():
      取分享令牌 → _walk 列目录
      对每个文件：
        若 个人云盘文件       → 直接用 file_id
        若 分享内文件         → copy_file 转存得到副本 file_id
        若 size >= SIZE_GATE  → 跳过 + notes
        download_url(副本) → 直链（fail 则退避重试）
        trash(副本)         → 回收（--no-clean 可关闭）
```

## 5. 使用方式

```bash
# 完整解析（默认：转存→取直链→回收）
python3 aliyun.py 'https://www.aliyundrive.com/s/xxxxxxxx'

# 仅列目录（不转存、不取直链，最轻）
python3 aliyun.py 'https://www.aliyundrive.com/s/xxxxxxxx' --list-only

# 保留云盘副本（不回收）
python3 aliyun.py 'https://www.aliyundrive.com/s/xxxxxxxx' --no-clean

# 打印凭据读取结果
python3 aliyun.py --creds

# JSON 输出（便于上级管道）
python3 aliyun.py 'https://www.alipan.com/s/xxxxxxxx' --json
```

## 6. 已知限制 / 待办

1. **体积门控**：免费账号 ≥ 约 100MB 取不到直链；会员能否解除 **待验证**。
2. **取直链频控**：已内建退避重试，但高并发下仍可能触顶，需控制节奏。
3. **转存留痕**：默认取到直链后回收，属正常使用；如担心账号风险可用 `--no-clean` 评估。
4. **token 续期**：refresh_token 长期有效；若 App 重新登录导致旧 token 失效，需重新 root 读取。
5. **非 root 环境**：无法直读 App DB，需用户手动提供凭据（`.cookie.aliyun` 或 `--token`）。

## 7. 与其它站点的差异对照

| 维度 | 迅雷 | 蓝奏 | 阿里云盘 |
|---|---|---|---|
| 凭据来源 | App root 直读 | 全匿名 | App root 直读（明文 DB） |
| 分享直链 | 直接可取 | 直接可取（WAF 求解） | **需先转存** |
| 多线程 | 分享链 ~6Mbps 封顶 | 直链 Range | **按连接限速，连接越多越快** |
| 默认并发 | 16 | 512 | 64 |
| 体积限制 | 无 | 无 | **≥100MB 取不到直链** |
